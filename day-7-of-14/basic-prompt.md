# Basic Prompt for Web Search Chatbot

Build a chatbot using Gradio, LangChain, Tavily, `chatbot.py`, and `app.py`.
Use Ollama with model `llama3.2:latest`.

## Instructions

- Create `app.py` for the Gradio UI.
- Create `chatbot.py` for the LangChain/Tavily chat logic.
- Use `ChatOllama` with `llama3.2:latest`.
- Use `TavilySearchResults` for web search.
- Keep the chatbot simple and functional.

## Example

User asks: "Who is the current president of the United States?"
Assistant: "Use Tavily to search the web and answer with the latest information."
