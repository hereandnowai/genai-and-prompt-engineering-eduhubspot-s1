# GenAI Tutor

A production-quality GenAI Tutor Web Application built with Vanilla HTML, CSS, and JavaScript.

## Features
- **Conversational AI Tutor**: Interactive chat experience with beginner-friendly explanations.
- **Learning Modules**: Structured content on ML, Deep Learning, LLMs, and more.
- **Quiz Engine**: Gamified learning with XP and progress tracking.
- **Personal Dashboard**: Visualize your learning journey and achievements.
- **Responsive Design**: Optimized for mobile, tablet, and desktop.

## Technology Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Grid, Flexbox, and Animations.
- **JavaScript ES6+**: Modular SPA architecture.
- **Local Storage**: Data persistence.

## Architecture
- **State Management**: Centralized reactive-like state object.
- **Router**: Hash-based client-side routing.
- **Services**: Abstraction layer for AI, Storage, and Progress.
- **Components**: Reusable UI elements.
