# GenAI Tutor - Modern AI Learning SPA

A production-quality Single Page Application (SPA) designed to educate beginners about Artificial Intelligence. Built entirely with **Vanilla JavaScript, HTML5, and CSS3**.

## 🚀 Vision
To provide a premium, interactive, and gamified learning environment where users can master AI concepts through:
- Conversational AI Simulations
- Visual Learning Modules
- Interactive Quizzes
- Gamified Progress Tracking

## 🛠 Architecture
- **SPA Framework:** Custom hash-based router.
- **State Management:** Centralized reactive state object.
- **Storage:** LocalStorage persistence for progress, settings, and sessions.
- **Modularity:** Component-based UI architecture.
- **Design:** Modern SaaS aesthetic with mobile-first responsiveness.

## 📂 Project Structure
- `/assets/js/pages`: Individual page components.
- `/assets/js/services`: Business logic (AI simulation, Storage, Quiz logic).
- `/assets/js/components`: Reusable UI elements (Navbar, Cards, Chat).
- `/assets/css`: Modular CSS architecture (Animations, Layout, Responsive).
- `/assets/data`: Mock educational datasets (JSON).

## ✨ Features
- **Conversational Tutor:** AI-simulated chat with beginner-friendly explanations.
- **Interactive Quizzes:** Real-time feedback and XP rewards.
- **Theme Support:** Native Dark/Light mode.
- **Gamification:** XP system, streaks, and achievement badges.
- **Progressive Disclosure:** Lessons broken down into digestible chunks.

## 📦 Getting Started
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. No build step or dependencies required!
